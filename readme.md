Bashka — a dual-panel commander for local and remote shells. Browse the filesystem, SSH/SFTP hosts, and archives side by side, run shell commands directly from the panels, and extend it with plugins built on a small core of catalog/command contracts. Built with Avalonia + Consolonia for a fast terminal UI
